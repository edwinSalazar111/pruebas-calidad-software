# Proyecto de pruebas de software y métricas de calidad

## Descripción
Proyecto académico desarrollado con Python y Flask, orientado a la aplicación de pruebas de software y al análisis de métricas de calidad.

## Tecnologías utilizadas
- Python
- Flask
- Unittest
- Requests

## Pruebas realizadas
1. **Prueba funcional:** validación de datos al registrar productos.
2. **Prueba de seguridad:** evaluación del rechazo de un patrón de entrada sospechoso en el inicio de sesión.

## Archivos
- `app.py`: implementación de los servicios de la aplicación.
- `test_pruebas.py`: casos de prueba automatizados.

## Propósito
Evaluar el comportamiento de la aplicación mediante dos pruebas y analizar tres métricas de calidad de software.

**Nota:** la prueba de seguridad es básica y no representa una protección completa contra inyecciones SQL.
